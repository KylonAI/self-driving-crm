Kylon email · architecture overview

Every client email in the CRM, every reply drafted for you, every send by a person

Mail reaches Kylon three ways: inboxes people connect, mailboxes Agents own, and shared addresses forwarded to an Agent. Each message is filed into the client's one thread in the CRM, an Agent drafts the reply there, and a person reads it and clicks send. The example below uses a made-up company, Amberline Studio.

1 · Three kinds of mailbox

Personal inbox

riley@amberline.example. Riley connects it once with her own sign-in. Only client conversations are captured; her personal mail stays out.

Agent mailbox

An Agent's own address, approved by a person who manages the Agent. It receives forwarded mail and files it to the right client.

Shared address

sales@ or info@. Either connected as its own account, or forwarded to an Agent mailbox when the provider has no direct connection.

2 · How mail reaches Kylon

flowchart LR
  G["Gmail or Microsoft 365 inbox"] -->|"owner connects, capture runs every 15 min"| CAP["Capture Automation"]
  I["Hosted IMAP inbox (IONOS and similar)"] -->|"forwarding or auto-BCC rule"| AM["Agent mailbox"]
  S["Shared address: sales@ or info@"] -->|"forward"| AM
  T["Support tool (Chatwoot and similar)"] -->|"webhook"| WH["CRM Room"]
  CAP --> IN["CRM intake"]
  AM -->|"Agent files it"| IN
  WH -->|"Agent files it"| IN
  IN --> REC["Client record and its thread"]

Every route ends at the same intake, which matches mail to a client only by exact email address or domain, never by name. Anything uncertain goes to a person to review instead of a guessed client.

3 · One client, one thread, a person sends

sequenceDiagram
  participant C as Client
  participant M as Mailbox
  participant K as Client thread in Kylon
  participant A as Agent
  participant P as Person
  C->>M: Email arrives
  M->>K: Captured: subject, snippet, link back
  A->>K: Drafts a reply as a Draft Card, using the client's history
  P->>K: Reads, edits, clicks send
  K->>C: Sent from the person's own mailbox
  M->>K: Sent copy captured, so the thread stays complete

Meeting recaps, support conversations and drafts for the same client land in the same thread. When a deal moves from sales to delivery, the stage changes and the thread stays.

5 · Privacy defaults

Only client mail

Captured: conversations with people outside your own domains, minus a personal skip list. Personal threads never enter Kylon.

Little text stored

Subject, a short snippet and a link back to the original by default. Full bodies only if you choose them.

Each person's own access

An inbox is read only with its owner's sign-in. Admins see client conversations in the CRM, not anyone's mailbox.

7 · How the setup runs

  1. Ask. The Agent asks about mailboxes, tools and privacy with short cards you click through.
  2. Look. With your OK, it reads mailbox headers (never bodies) to see which addresses and tools carry client mail.
  3. Design. It writes this kind of page for your business and asks you to approve it.
  4. Build. Only after approval: Agent mailboxes, connections, forwarding with a test message, history import with a trial, then a checklist of what is live.
